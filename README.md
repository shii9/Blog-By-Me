# Blog By Me

Welcome to my personal knowledge base! This repository serves as a centralized hub for my blogs, tutorials, cheat sheets, and technical notes on web development, cybersecurity, Linux, and security operations.

---

## 📝 Article Directory

### 🌐 Network & Command Line Utilities

- [curl: The Complete Reference (Beginner to Advanced)](https://github.com/shii9/Blog-By-Me/blob/main/curl_mastering.md) - A comprehensive reference on `curl`, covering fundamentals, flags, HTTP requests, file transfers, authentication, troubleshooting, and practical examples.
- [Mastering FFUF: The Complete Guide to Web Fuzzing with FFUF](https://github.com/shii9/Blog-By-Me/blob/main/ffuf_mastering.md) - A complete guide to web fuzzing with FFUF, including installation, discovery techniques, filtering, virtual host enumeration, and automation.

### 🐧 Linux & File System

- [Mastering `find`: File Discovery, Recon, and Forensics on Linux](https://github.com/shii9/Blog-By-Me/blob/main/find_mastering.md) - A detailed guide to the Linux `find` command, covering file discovery, permissions, timestamps, SUID/SGID checks, credential discovery, persistence hunting, incident response, and safe automation.

### 🛡️ Security Operations & SIEM

- [Building a SOC Home Lab: Centralized Windows & Linux Security Monitoring with Splunk](https://github.com/shii9/Blog-By-Me/blob/main/soc_lab_splunk.md) - A complete walkthrough of building a multi-platform security monitoring lab with Splunk, including log collection, dashboards, detections, and security analysis.
